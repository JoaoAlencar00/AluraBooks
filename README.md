# AluraBooks

Interface de uma livraria digital desenvolvida durante os estudos de responsividade da Alura.

## Recursos da interface

- Menu de categorias com estados controlados por CSS.
- Carrosséis de livros com Swiper.
- Cartões de recomendação e de autora em destaque.
- Seções de tópicos, novidades e rodapé.
- Layout adaptado por media queries, incluindo larguras de 1024 e 1728 pixels.

## Tecnologias

HTML5, CSS3, Flexbox, media queries e Swiper 8 carregado por CDN.

## Como executar

Clone ou baixe o repositório e abra `index.html` em um navegador. Não há instalação de dependências ou etapa de build.

É necessária conexão com a internet para carregar Google Fonts e Swiper.

## Organização

- `index.html`: estrutura da página e configuração do carrossel.
- `styles.css`: variáveis e importação dos estilos.
- `styles/`: estilos organizados por seção.
- `reset.css`: normalização.
- `img/`: capas, marcas e ícones.

## Escopo e aprendizados

O foco é a construção de uma interface responsiva. Busca, favoritos, carrinho e cadastro de e-mail são elementos demonstrativos e não possuem integração com backend.

O projeto exercita organização de CSS por componentes, tipografia, composição de cartões e adaptação de navegação.

Projeto educacional da Alura. Marcas, capas e demais imagens pertencem aos respectivos titulares.
